# ✂️ Projeto Barbearia

## 🚀 Sobre o projeto

Projeto didático de **landing page para barbearia**, desenvolvido utilizando **HTML e CSS**.
Foi inspirado no vídeo do **Sujeito Programador** e teve como objetivo treinar boas práticas de estilização e estruturação de uma página moderna.

Esse é um dos projetos mais bonitos que desenvolvi até agora, com foco em design e responsividade.

## 🌐 Demonstração

👉 [Acesse a página no GitHub Pages](https://lepofernandes.github.io/Projeto-Barbearia/)
👉 [Repositório no GitHub](https://github.com/LepoFernandes/Projeto-Barbearia)

## 🛠 Tecnologias

* HTML5
* CSS3

## ⚙️ Como rodar localmente

1. Clone o repositório:

   ```bash
   git clone https://github.com/LepoFernandes/Projeto-Barbearia.git
   ```
2. Acesse a pasta do projeto:

   ```bash
   cd Projeto-Barbearia
   ```
3. Abra o arquivo `index.html` no navegador.

## 📌 Aprendizados

Esse projeto me ajudou a:

* Melhorar a organização do código CSS
* Trabalhar com layouts mais atraentes e responsivos
* Praticar construção de uma landing page moderna
